# Contributing

Thanks for helping improve Codex Profile Switcher.

## Before You Start

- Open an issue before starting a large change so the direction is agreed first.
- Do not include credentials, auth files, logs, or machine-specific artifacts in a change.
- Treat `~/.codex/` and `~/.codex-switcher/` as user data. Tests must use an isolated home and file-backed vault.

## Development

Use the SwiftPM targets under `Sources/`. Do not add root-level Swift files or separate script-only source lists.

```bash
./build.sh
make check
```

Use four-space indentation and keep functions short. The project uses Cocoa, SwiftUI, Security, Foundation, and Sparkle only.

## Pull Requests

- Use a conventional commit prefix such as `fix:`, `feat:`, `docs:`, or `test:`.
- Run `make check` before opening a pull request.
- Update documentation when behavior changes.
- Include a screenshot for menu or settings UI changes.
- Never add automated tests that access the real macOS Keychain.

Public releases require a committed Sparkle `appcast.xml` update generated by `Scripts/release_app.sh`. See [the release guide](docs/RELEASING.md) for signing, notarization, and Homebrew publishing.
